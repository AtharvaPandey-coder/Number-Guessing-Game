# Number Guessing Game 🔢

A simple command-line game in Python where you try to guess a randomly generated number between 1 and 100.

## Rules
- The computer picks a secret number between 1 and 100.
- You keep guessing until you find it.
- After each guess, you're told whether to go higher or lower.
- The game tracks how many attempts it took you.

## How to Play
1. Run the script:
```bash
   python number_guessing_game.py
```
2. Enter a number when prompted.
3. Keep guessing based on the hints until you get it right.
